## Featured Project: Mo' Rockets

<p align="center">
  <a href="https://www.newgrounds.com/portal/view/999410">
    <img src="https://github.com/EvasiveAce/mo-rockets/blob/main/Common/MainMenu/Sprites/NewGrounds.png?raw=true" alt="Mo' Rockets game artwork" width="720">
  </a>
</p>

**Mo' Rockets** is a browser-based rocket-building game I developed and released on Newgrounds using **Godot and GDScript**.

- **12 unlockable rockets** and **24 paint options**
- Persistent multipliers, plus save import/export
- Fixed bugs and refined gameplay based on player feedback and crash reports
- Reached **11,500+ views** and was featured on the Newgrounds front page in September 2025
